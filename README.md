# 🎓 Student Management System

A simple and professional Flask-based Student Management System built using Python, Flask, SQLite, Bootstrap, and Chart.js.

---

## 🚀 Features

✅ Student CRUD Operations  
✅ Add Student  
✅ Edit Student  
✅ Delete Student  
✅ Search Student by Name or ID  
✅ Login Authentication  
✅ Dashboard Analytics  
✅ Grade Distribution Pie Chart  
✅ PDF Export Feature  
✅ Responsive Bootstrap UI  
✅ SQLite Database Integration  

---

## 🛠 Technologies Used

- Python
- Flask
- SQLite
- Bootstrap 5
- Chart.js
- ReportLab

---

## 📊 Dashboard Features

- Total Students Count
- Passed Students Count
- Failed Students Count
- A+ Students Count
- Interactive Pie Chart Analytics

## ⚙️ Installation

### 1️⃣ Clone Repository

```bash
git clone https://github.com/SowndammalM/Student_Management_System.git
```

---

### 2️⃣ Move into Project Folder

```bash
cd Student_Management_System
```

---

### 3️⃣ Install Requirements

```bash
pip install flask reportlab
```

---

### 4️⃣ Run Application

```bash
python app.py
```
